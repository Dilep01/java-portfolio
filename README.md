# Dilep Kumar K — Java full-stack portfolio

A separate portfolio for the three Java projects, built in the supplied folder. Warm ivory, cobalt blue, an animated exploded-layer illustration, project case studies, an interactive workflow explorer, and responsive layouts distinguish it from the dark Data Science portfolio.

## Run

Requires Node.js 20 or newer. No packages or API keys are needed.

```powershell
npm run dev
```

Open http://127.0.0.1:4173. `npm run check` checks JavaScript syntax. `npm run build` copies the static site into `dist/`. `node scripts/serve.mjs --dist` previews that output. Static files can also be hosted under a subdirectory; asset links are relative.

## Interactions and accessibility

Case studies open native dialogs with keyboard dismissal and focus restoration. Architecture tabs support Left/Right arrows and Home/End; each stage and the Next step control update its explanation. The small-screen navigation supports Escape. Motion respects the operating system preference and can be paused with a persistent setting. The contact button copies the email address when browser clipboard permission permits; email and social links work directly. No message is sent by the website.

Google Fonts are optional enhancements with local system fallbacks. All illustrations and application assets are local. No analytics, backend, contact-form service, or paid API is used.
